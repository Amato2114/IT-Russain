# 📉 RetailLoss Sentinel

**Интеллектуальный анализ потерь в рознице** на базе Streamlit

---

## 🔍 Что делает приложение

Загрузите Excel-файл с историей потерь и за считанные секунды получите:

- 📊 **Обзор** по магазинам, категориям, датам
- 📈 **Прогноз** потерь на будущее (Prophet)
- 🎯 **ABC / XYZ / Pareto**-анализ
- 🔎 **Аномалии** и кластеры потерь
- 💰 **What-if** сценарии экономии
- 📥 **Полный отчёт Excel** одной кнопкой

---

## 📁 Формат входного файла

Приложение **автоматически распознаёт** колонки, но для лучшего результата желательно наличие:

| Колонка         | Описание                        | Пример       |
| ---------------------- | --------------------------------------- | ------------------ |
| Дата               | День списания               | 01.02.2025         |
| Категория     | Товарная группа           | Смартфоны |
| СуммаПотерь | Сумма убытка в валюте | 12 345 ₽          |
| Магазин         | Название или ID точки   | Магазин_01  |

&gt; ❗️ Колонки могут называться **как угодно** — приложение само найдёт нужные по ключевым словам и типу данных.
